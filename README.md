# customizationLinux
to begin with, I will be giving personalization, I will give credits to the person who made the scripts. I focus on giving personalization to those people who have no prior knowledge of arch, so in this repository you will find all kinds of personalization.
First step for customization: changing the image in Fastfetch. To do this, we will use a tool called OpenCode, which simplifies the process and helps avoid errors when setting up the image in Fastfetch.
Second step: Use OpenCode to display the image in your terminal by providing the image's file path; OpenCode will handle all the necessary steps, and you're all set.
